# منصة حفظ النعمة (Hefz Al-Ne3ma Platform)
## منصة ذكية لإدارة فائض الغذاء والمخلفات العضوية وفق مبادئ الاقتصاد الدائري
**"نحفظ النعمة ... و نصنع منها قيمة"**

---

### 📁 محتويات مجلد الموقع (Website Package)
هذا المجلد يحتوي على كافة ملفات المنصة جاهزة 100% للرفع المباشر على **GitHub Pages** أو أي استضافة ويب:

1. **`index.html`**: الصفحة الرئيسية الشاملة لكافة البوابات (الجمهور والأسر، مركز الفرز، أصحاب المشروعات، لوحة المبادرة الخضراء).
2. **`style.css`**: ملف التنسيقات البيئية الحديثة فائقة الحيوية، ودعم RTL، وتأثيرات Glassmorphism المتطورة.
3. **`app.js`**: محرك التفاعل، إدارة المحفظة والنقاط والكاش، الخريطة التفاعلية، ورسوم Chart.js البيانية.
4. **`logo.png`**: الشعار الرسمي المعتمد للمشروع.
5. **`hero_banner.jpg`**: لوحة الواجهة التفاعلية ثلاثية الأبعاد للحي المستدام.
6. **`diagram_model.png`**: المخطط التوضيحي لمنظومة الاقتصاد الدائري.
7. **`diagram_streams.png`**: مخطط مسارات الفرز والتحويل الاقتصادي الـ 5.
8. **`.nojekyll`**: ملف لتعطيل محرك Jekyll على GitHub لضمان عمل كافة الملفات والمسارات بسلاسة.

---

### 🚀 خطوات الرفع على GitHub Pages بدون أي أخطاء 404:
1. افتح المستودع على GitHub: `https://github.com/sustainabilityeg/Preserving-the-blessing`
2. ارفع **محتويات هذا المجلد مباشرة (وليس المجلد كفولدر داخلي)** حتى يكون `index.html` في الواجهة الرئيسية للمستودع.
3. توجه إلى **Settings** ⬅️ **Pages**:
   - اختر **Source:** `Deploy from a branch`
   - اختر **Branch:** `main` (أو `master`) والمجلد `/ (root)`
   - اضغط **Save**.
4. انتظر دقيقة واحدة، وافتح رابط الموقع:  
   `https://sustainabilityeg.github.io/Preserving-the-blessing/`
